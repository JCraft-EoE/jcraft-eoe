# Changelog
## General
* **new Ranger Spec**, use `/spec about`
* Counters no longer trigger on projectiles, poisons and very weak non-stand attacks
### Stands & Specs
* Ranger Spec:
  * Can roll and slide
  * Has a free item space (holster)
  * Use Holster item to unlock Spec
  * Focus move make all projectiles owned by the user homed in on the highlighted entity
* Introduced Spec damage type
* Nerfed HG heavy
* Aerosmith:
  * Bomb inertia improved
  * Overheat is harsher now
* Poison UI for PHD:
  * Purple indicates normal virus status effect
  * White indicates virus cleanse, removing the affected entity's virus effect
  * Black indicates blindness, weakness, and slowness
* C-Moon:
  * Updated skins and animations
  * Buffed cr.H
* GE:
  * New cr.S2 and cr.Hvy
  * Updated Tree and Vine models
  * Made Vine setups easier
* Nerfed TW Donut
* Nerfed MiH Speed
* Buffed STW Special 3
* Minor SC rework
* Rebalanced the Sun
* Vampire:
  * Nerfed Bloodsuck
  * Added cooldown to blood bottles
* Buffed Hamon Wave
* Nerfed Anubis damage
* Colour corrections for SPTW Skin 1
* New Mandom sounds
* Force-feeding via Throwing now requires hunger on the target
* Nerfed ts damage scaling
* Increase starting gauge amount
* Stands are now immune to cacti
* Stand Disc image updates
### Blocks & Items
* Fragile Discs introduced: Spec and Stand discs that can only be used once
* Added recipe for Bullet item
* Added Peacemaker item: it's a gun that needs Bullets
* Added Holster item: use to get Ranger Spec
* Guns share a cooldown now
* Bullet projectiles are now armor-piercing
* Added aiming to gun, reducing its spread
### Effects
* Out-of-Body effect knocks camera out
### Languages
* Added Italian and Chilean-Spanish translation
### Bug Fixes
* Fixed Anubis infinite Combo
* Fixed SHA dealing double damage

* Fixed PH chasing Hamon Wave
* Fixed Pointed Dripstone crash when dropped by AS
* Fixed time-stopping remote stands
* Fixed The Fool Ult erasing blocks
